# SALMAN FARSHI — Premium Payment Center

এটি একটি সহজ static website। কোনো hosting/server/database লাগবে না।

## ১) তথ্য পরিবর্তন
`script.js` ফাইল খুলে:
- YOUR_BKASH_NUMBER → আপনার bKash নম্বর
- YOUR_NAGAD_NUMBER → আপনার Nagad নম্বর
- YOUR_ROCKET_NUMBER → আপনার Rocket নম্বর
- YOUR_UPAY_NUMBER → আপনার Upay নম্বর
- YOUR_CELLFIN_NUMBER → আপনার CellFin নম্বর
- YOUR_MCash_NUMBER → আপনার mCash নম্বর
- YOUR_BANK_ACCOUNT_NUMBER → ব্যাংক অ্যাকাউন্ট নম্বর

## ২) Netlify-তে চালু করা
1. Netlify-তে লগইন করুন।
2. এই ZIP ফাইলটি extract করুন।
3. `index.html`, `style.css`, `script.js` একই folder-এ রাখুন।
4. Netlify-এর নতুন site/deploy অংশে folder/ZIP upload করুন।
5. Deploy হলে আপনার নতুন website link পাবেন।

## ৩) GitHub-এ রাখা
GitHub repository-তে তিনটি ফাইল upload করুন:
- index.html
- style.css
- script.js

তারপর GitHub Pages অথবা Netlify দিয়ে publish করতে পারবেন।

## গুরুত্বপূর্ণ
Website-এ ব্যক্তিগত মোবাইল/ব্যাংক তথ্য প্রকাশ্যে দেওয়ার আগে নিশ্চিত হোন যে তথ্যগুলো প্রকাশ করার অনুমতি আপনার আছে।
